# GlassWall Public Directory

This directory contains static assets that are served directly by the web server.

## Contents

- Images and icons
- Static HTML files
- Client-side JavaScript files
- CSS stylesheets
- Font files
- Other static resources

## Why This Directory Exists

Vercel requires a non-empty `public` directory for deployment. This README ensures the directory exists and is not empty, preventing the "The Output Directory 'public' is empty" error during deployment.
